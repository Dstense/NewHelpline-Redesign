# NewHelpline Redesign

Responsive static website redesign preserving the original orange, blue and pale-blue brand palette.

## Run locally
Open `index.html` in a browser. For a local server, run `python -m http.server 8000`.

## Deploy
Deploy the root directory to Netlify; `netlify.toml` configures the publish directory.

## Notes
This is a static site; the enquiry form opens WhatsApp with a prefilled message. Review business contact details before commercial launch.
